## 2. Supervisor

`p2_multimodal_service.sh`管理一个MediaMTX子进程和一个
`p2_multimodal_fusion`子进程：

```text
start -> supervisor -> MediaMTX + p2_multimodal_fusion
                         |                 |
                         `--任一退出------> 终止另一方、记录重启次数、重新启动
stop  -> stop.request -> 终止业务/MediaMTX -> brightness=0 -> 删除PID文件
```

- 默认业务进程不启用自动补光，必须设置`P2_AUTO_ILLUMINATION=1`才会开启。
- 业务默认运行86400秒，由supervisor负责外部停止和异常重启。
- 子进程PID、重启次数、summary/events和完整日志保存在`P2_SERVICE_DIR`，默认
  `/tmp/p2-multimodal-service`。
- stop路径和supervisor退出路径都会写入`/sys/class/leds/zzh:white:fill/brightness`
  的0；业务自身也在析构/显式shutdown中归零。
- 采集、推理、融合、编码和RTSP失败不被吞掉：应用退出并由supervisor重新拉起。

常用命令：

```sh
P2_SERVICE_DIR=/tmp/p2-service /usr/bin/p2_multimodal_service.sh start
P2_SERVICE_DIR=/tmp/p2-service /usr/bin/p2_multimodal_service.sh status
P2_SERVICE_DIR=/tmp/p2-service /usr/bin/p2_multimodal_service.sh stop
```

## 3. 资源摘要

`p2_multimodal_fusion`摘要中的`process`对象：

| 字段 | 语义 |
|---|---|
| `peak_vm_kb` | 进程`VmPeak`峰值地址空间指标，不是RSS |
| `final_rss_kb` | 结束前`VmRSS` |
| `final_threads` | 所有工作线程join后的线程数 |
| `open_fds` | 结束前`/proc/self/fd`数量 |

60秒整链结果为峰值VmPeak约640880 KB、结束RSS约35876 KB、线程2、fd33；20秒资源
重开摘要为峰值VmPeak约431892 KB、结束RSS约32180 KB、线程1、fd20。两小时结果为
峰值VmPeak 582720 KB、结束RSS 41760 KB、线程2、fd33；运行前后`MemAvailable`
变化约11 MB并伴随文件缓存增长。上述指标用于运行前后比较，不等同于内核级泄漏证明。

## 4. 真机门禁

### 4.1 60秒长稳

精确提交`2c26c31d5303`：1795可见光编码帧、454热融合对、1795/1795 RTSP发布包，
可见光/编码/fusion队列全部0淘汰，发布失败0；RGA/MPP平均11.410/5.324 ms。
`ffmpeg`客户端连续读取5秒无错误，应用最终PASS，结束LED保持0。

### 4.2 业务进程故障

启动supervisor后读取RTSP，向业务app发送SIGTERM。supervisor记录
`restart_count=1`并重启业务，第二次客户端读取成功；status显示新的app和
MediaMTX PID均处于RUNNING。

### 4.3 MediaMTX故障

向MediaMTX子进程发送SIGTERM。应用收到Broken pipe并退出，supervisor重建两方，
`restart_count=2`并恢复`p2`发布；客户端采用有界重试，恢复后读取成功。
随后stop清理所有子进程，LED brightness=0，PID文件被删除。

### 4.5 当前边界

- 两小时内应用至本机MediaMTX的发布会话持续存在，215994个RTSP包写入成功；
  FFmpeg客户端仅在开始阶段读取5秒，不能表述为外部客户端连续解码两小时。
- 自动补光在本次长稳中保持默认关闭；本次验证关闭状态和退出归零，不重复替代
  P2.6受控渐亮、保持、渐暗和故障默认关门禁。
- 未做8小时/24小时长稳、断网、磁盘满、MediaMTX配置损坏、NFS断开或内核级
  I/O故障注入，这些属于后续可选强化项。
- 临时跨光谱标定仍只适用于固定姿态和1 m附近的粗粒度ROI，不升级为像素级对齐
  或绝对测温精度结论。
