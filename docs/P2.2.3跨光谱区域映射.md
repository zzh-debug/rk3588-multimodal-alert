# P2.2.3 跨光谱区域映射

> 建立日期：2026-08-27（Asia/Shanghai）<br>
> 当前状态：软件基线已通过；D110/BAA型号及最终横/竖安装姿态已确认，真实拟合和独立验证尚未完成

## 1. 目标与适用边界

本阶段只做“固定安装、限定距离、区域级”映射：把MLX90640热区域投影成IMX415
可见光画面中的四边形和保守轴对齐包围框，用于人员检测框与热目标的规则匹配。
首版采用平面单应矩阵，不声明像素级配准，也不假设不同深度物体没有视差。

一个标定配置只对其记录的刚性支架、分辨率和距离范围有效。相机相对位置、焦距、
方向或分辨率改变后必须重新标定。配置中的训练残差不能代替独立验证点误差。

## 2. 型号和FOV的可靠判据

本地Melexis MLX90640数据手册Revision 11明确给出：

| 金属封装型号 | 典型水平FOV | 典型垂直FOV | 激光标记第三位 |
|---|---:|---:|---|
| `MLX90640-ESF-BAA` | 110° | 75° | `A` |
| `MLX90640-ESF-BAB` | 55° | 35° | `B` |

激光标记是传感器金属封装上的10位字符，不是Waveshare PCB背面的`MLX9064x`
丝印。当前模组的黑色光学结构遮住了该字符，不应为读取字符而拆卸光学结构。
2026-08-27结合实物正反面照片与微雪商品页的D55/D110并列外观确认：实物为
低矮圆环、小中央孔的D110光学结构，而非D55的高筒镜头。因此项目硬件冻结为：

| 项目 | 确认值 |
|---|---|
| 微雪模组 | `MLX90640-D110 Thermal Camera` |
| Melexis型号 | `MLX90640-ESF-BAA` |
| 典型FOV | 水平110°、垂直75° |

仓库未保存聊天原图；识别依据和事实边界另见阶段证据说明。

## 3. 坐标契约

| 对象 | 定义 |
|---|---|
| 热坐标 | 32x24；左上像素中心为`(0,0)`，列向右、行向下；整个阵列外边界为`[-0.5,31.5] x [-0.5,23.5]` |
| 可见光坐标 | 像素中心坐标；左上为`(0,0)`，向右/下为正；配置记录宽高 |
| 点映射 | `p ~ H * [thermal_x, thermal_y, 1]^T`，配置保存行优先3x3矩阵 |
| 热区域 | 输入列/行上下界均为闭区间；映射其像素单元四个外角，不只映射中心 |
| 输出 | 投影四边形、未裁剪AABB、裁剪到可见画面的AABB和是否相交 |
| 融合分数 | 当前使用“可见检测框与热区域裁剪AABB交集 / 热区域AABB面积”；旋转/透视下是保守区域级近似 |

## 4. 已实现软件

| 组件 | 内容 |
|---|---|
| `p2_calibration` | 严格键值配置解析、BAA/BAB到FOV映射、配置使用门禁、点/区域投影和覆盖率 |
| 单应拟合 | 至少4组对应点；源/目标坐标归一化后最小二乘求解；拒绝共线/退化输入，输出RMSE和最大重投影误差 |
| `p2_calibration_fit` | 读取CSV对应点；只有型号、尺寸、距离和最大误差门禁通过才写`calibrated`配置 |
| `p2_cross_spectral_probe` | 加载配置、映射热区域、可选计算与可见ROI覆盖率，并输出可审计JSON |
| `p2_calibration_capture` | 以完整热帧为触发，保存其后首个4K可见光Y帧、32×24温度CSV、伪彩PPM、原始ZMLX和双路时间戳清单；默认允许100 ms偏差，只用于静态平面靶采集，不在保存前旋转原始坐标 |
| 模板 | `configs/cross_spectral_calibration.template.conf`故意保持未标定状态，不能直接用于业务 |

原生测试覆盖仿射/透视拟合、序列化往返、区域边界、覆盖率、共线点、异常点残差、
重复/未知配置键、未确认型号、未标定状态、奇异矩阵和越界热区域。

## 5. 合成AArch64门禁

精确提交`3501809f3003`在Linux 5.10.209 AArch64板端完成：6组合成对应点拟合
RMSE/最大误差低于`1e-6 px`显示精度；热区域`[2,4]-[3,5]`映射为
`[240,377.5]-[480,547.5]`，指定可见ROI覆盖率为0.5；未标定模板返回FAIL和
退出码1。该门禁不采集真实摄像头，不属于物理标定证据。

## 6. 真实标定操作顺序

1. 【已完成】确认微雪D110，对应`MLX90640-ESF-BAA`、110°×75°；
2. 【姿态已冻结】热相机PCB横向、IMX415 PCB纵向，两个镜头面向同一场景且不再改变相对位置；正式采集前仍需记录机械基线并复核固定牢靠、无遮挡；
3. 冻结可见光分辨率，并明确目标使用距离；
4. 使用可见光和长波红外都清晰的静态平面靶，通过`p2_calibration_capture`保存双路样本，在画面边缘和中心均匀采集对应点；真实拟合建议不少于8点，另留独立验证点；
5. 用`p2_calibration_fit`生成配置，人工复核最大残差与点分布；
6. 对未参与拟合的点/区域统计P50、P95和最大误差，并在距离范围两端复测；
7. 只有独立验证通过后，才能把配置的`state`和区域映射写成完成成果。

当前型号和最终横/竖姿态已确认，但尚无真实跨光谱对应点与独立验证数据，因此
P2.2整体仍未关闭。下一步是记录安装基线/使用距离并采集真实标定靶数据。
