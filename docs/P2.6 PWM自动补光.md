# P2.6 PWM自动补光

## 1. 当前实现

P2.6.1完成了可见光亮度遥测、IMX415实时曝光/模拟增益读取、补光状态机和
PWM LED安全封装。补光默认关闭，只有显式传入`--auto-illumination`才允许业务
程序写入`/sys/class/leds/zzh:white:fill/brightness`。

状态转移为：

```text
OFF -> DARK_PENDING -> RAMP(up) -> ON
                              \\-> HOLD -> RAMP(down) -> COOLDOWN -> OFF
任何无效/回退时间戳/硬件写失败 -> FAULT -> brightness=0
```

正常照明只保持`OFF`；暗场且持续存在人员热证据时，先经过1秒暗场确认，再按
4级、250 ms步进渐亮，最多达到安全上限32。目标热证据消失后保持2秒，再按同样
步进渐暗并进入3秒冷却，防止照明频闪和目标边缘抖动。退出时主程序显式调用
`shutdown()`并写入brightness 0，析构函数再次提供兜底关闭。

## 2. 判定输入

### 2.1 可见光亮度

对当前3840x2160 NV12 Y平面取中心90%区域的有界采样，计算mean、P10、P50、P90、
暗像素比例和高亮像素比例。默认暗场条件为：

| 条件 | 默认值 |
|---|---:|
| P50上限 | 60 |
| P90上限 | 110 |
| 自适应停灯P50 | 82 |
| 自适应停灯P90 | 145 |

### 2.2 AIQ曝光/增益

从动态发现的IMX415 V4L2 subdevice读取`V4L2_CID_EXPOSURE`和
`V4L2_CID_ANALOGUE_GAIN`，按各自控制范围归一化。当前板端实测控制值约为
exposure 1300~1550、analogue gain 40；接口正常时作为亮度判定的“AIQ已抬高”
条件。无法读取或控制值非有限时，控制器进入`FAULT`并关闭LED。

### 2.3 持续热目标

P2.4融合结果`person_with_thermal_evidence`作为持续热目标输入。它已经包含
人员框、热ROI、相对背景升温和2帧确认/3帧释放去抖；P2.6不自行重复热像素
判定，也不把单次人员检测当作补光触发。

默认触发逻辑：

```text
dark = (P50 <= dark_p50_max) AND (P90 <= dark_p90_max)
       AND (exposure_ratio >= 0.55 OR gain_ratio >= 0.15)
trigger = dark AND person_with_thermal_evidence
```

## 3. 安全边界

- LED class路径默认`/sys/class/leds/zzh:white:fill`，最大命令亮度固定为32，
  不执行255长时间满亮。
- `SysfsPwmLed`初始化先读取`max_brightness`，写入0并读回校验；每次非零写入
  都读回确认，失败计数并进入FAULT。
- 状态机拒绝时间戳回退、无效Y统计、无效曝光/增益归一化和缺少状态方向。
- 任意采集/推理/温度/融合错误会停止主循环；自动补光退出前仍显式写0。
- P2.6只验证控制逻辑、sysfs命令、状态转移和安全归零。没有示波器、电流计和
  温度计，不声明PWM波形、LED电流、功耗、光照增益或温升。

结束brightness 0。集成提交的正式自动模式结果如下：

| 集成受控触发 | 8秒，59融合对，DARK_PENDING/RAMP/ON，目标8，退出OFF |

受控触发使用阈值覆盖当前实验室场景，只验证“真实融合结果可以驱动真实PWM”

`evidence/stage6/2026-08-30/`。

## 5. 运行方式

默认模式不控制LED：

```sh
/usr/bin/p2_multimodal_fusion --duration-sec 30
```

显式开启自动补光：

```sh
/usr/bin/p2_multimodal_fusion --duration-sec 30 \\
    --auto-illumination \\
    --illumination-events /tmp/p2-illumination-events.csv
```

`p2_illumination_probe`可单独验证亮度、曝光/增益和控制器；`--force-dark`与
`--forced-thermal-sec`只用于受控门禁，不能作为真实暗场结论。

下一步是整链P2.7可靠性验收：自动启动、采集/推流故障恢复、更长时间运行、
资源统计和结束后重开。LED自动控制仍保持默认关闭。
