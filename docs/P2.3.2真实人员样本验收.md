# P2.3.2 真实人员样本验收

> 目标：验证已经部署的 YOLOv5s RKNN 模型在本机相机、当前安装方向和实际场景下
> 的人员检测效果。本阶段只做评估，不训练、不微调模型，也不把原始人物图片提交
> 到 Git。
>
> 当前结论：2026-08-29两轮共125张真实样本通过预冻结门槛，P2.3按本文限定范围
> 正式关闭。

## 1. 验收边界

现成 COCO 人员模型已经用于 P2.3.1。P2.3.2 检查的是完整部署链路，而不是重新
制作训练集：

```text
IMX415 NV12 -> 当前安装方向 -> RGA旋转/letterbox -> RKNN INT8
             -> person后处理 -> 预览坐标 -> 人工真值框 -> Precision/Recall/F1
```

小型样本只能支持当前设备和场景的工程验收，不能表述成通用 mAP、模型重新训练
或大规模泛化结论。

## 2. 工具与数据格式

| 工具/文件 | 作用 |
|---|---|
| `p2_person_dataset_capture` | 板端低频抽样，保存缩小BMP并记录同帧模型预测 |
| `tools/person_dataset_annotator.html` | 笔记本浏览器中拖框，导出真值 `annotations.csv` |
| `p2_person_evaluate` | 以置信度和IoU门槛做逐图贪心匹配，输出Precision、Recall、F1及失败清单 |
| `manifest.csv` | 图片、V4L2 sequence/单调时间戳、原始/预览尺寸和旋转方向 |
| `predictions.csv` | 模型在预览图坐标中的置信度和人员框 |
| `annotations.csv` | 人工真值人员框；无人图片不写框，但仍由manifest计入负样本 |
| `capture-summary.json` | 应用提交、模型哈希、RKNN版本、采集错误和样本统计 |

采集工具拒绝覆盖已经存在 `manifest.csv` 的目录。抽样发生在 V4L2 回调有效期
内，不保留悬空Buffer指针，也不改变P2.1的Buffer生命周期。本工具不是P2.4异步
流水线，低频抽样时的BMP生成和推理耗时必须与P2.4性能事实分开记录。

## 3. 当前方向烟测

2026-08-29在当前刚性同向安装上分别采集0°、90°顺时针、180°和270°顺时针
预览。结果确认：

- `270cw`为人物和实验室场景正立方向；
- P2.3.1历史基线使用的`90cw`已经不适用于当前安装；
- 270°预览为540×960，模型在烟测帧检出1人，置信度约0.656；
- 4次启动均成功输出BMP/manifest/predictions，V4L2坏bytesused、缺失单调时间戳
  和sequence gap均为0。

方向烟测只证明图像/坐标链路可用，不替代真实样本准确率验收。

## 4. 正式采集协议

建议第一轮采集80张、间隔1秒，至少包含：

| 场景 | 建议数量 | 要点 |
|---|---:|---|
| 无人负样本 | 15 | 空场景、椅子和实验台，统计误检 |
| 中心单人 | 15 | 站立、坐姿、正面和侧面 |
| 画面边缘 | 15 | 左、右、上/下边缘及部分出画 |
| 距离变化 | 20 | 约0.7 m、1 m、2 m及可用最远位置 |
| 遮挡/较暗 | 15 | 桌椅遮挡、背对、正常关灯后的实际低照度 |

板端命令：

```bash
p2_person_dataset_capture \
  --output /tmp/p2-person-real-01 \
  --samples 80 \
  --interval-ms 1000 \
  --duration-sec 600 \
  --warmup 10 \
  --preview-edge 960 \
  --rotation 270cw
```

采集结束后立即把目录复制到开发机。原始人物图片默认不提交Git；仓库只保存经
用户确认可入库的汇总JSON、失败统计、文件哈希和复现命令。

## 5. 标注和评估

在笔记本打开 `tools/person_dataset_annotator.html`，选择数据集的全部
`images/*.bmp`。逐张沿人物可见外沿拖框；一人一个框，无人图直接确认。完成后
导出的 `annotations.csv` 覆盖数据集中的空模板文件。

```bash
p2_person_evaluate \
  --manifest manifest.csv \
  --annotations annotations.csv \
  --predictions predictions.csv \
  --confidence 0.25 \
  --iou 0.50 \
  --min-precision 0.80 \
  --min-recall 0.80 \
  --json evaluation.json \
  --failures failures.csv
```

第一轮工程门槛固定为IoU 0.50、置信度0.25、Precision不低于0.80且Recall不低于
0.80。若未通过，先按 `failures.csv` 区分方向/坐标错误、过暗、遮挡、小目标和
阈值问题，再决定调阈值、补数据或更换模型；不得直接用预测框冒充人工真值。

## 6. P2.3关闭条件

以下条件同时满足后才关闭P2.3：

1. 当前安装方向固定为`270cw`并在样本manifest中记录；
2. 至少60张有效图片，同时包含人员正样本和无人负样本；
3. 人工真值、预测和manifest通过严格格式/坐标校验；
4. Precision和Recall达到预先冻结的第一轮门槛；
5. 保存提交、模型哈希、采集摘要、评估JSON、失败清单和复现命令；
6. 文档明确结果是当前设备/场景的小样本工程验收，不是通用模型精度。

## 7. 2026-08-29正式结果

实际采集分两轮完成。人工在浏览器标注器中逐张审核模型建议框，并将只有孤立手臂
而无可识别头肩/躯干的画面按非person处理。

| 指标 | real-01 | real-02 | 汇总 |
|---|---:|---:|---:|
| 图片 | 80 | 45 | 125 |
| 正样本/负样本 | 20 / 60 | 6 / 39 | 26 / 99 |
| 人员实例 | 20 | 6 | 26 |
| TP / FP / FN | 20 / 0 / 0 | 6 / 0 / 0 | 26 / 0 / 0 |
| Precision | 1.000 | 1.000 | 1.000 |
| Recall | 1.000 | 1.000 | 1.000 |
| F1 | 1.000 | 1.000 | 1.000 |

两轮采集均为`270cw`、置信度0.25、IoU 0.50；125张抽样期间sequence gap、坏
bytesused和缺失单调时间戳均为0。原始图片和逐图CSV只保存在私有数据目录，Git
证据见`evidence/stage3/2026-08-29/`。

样本只包含一名人员、同一实验室且主要为正常照明。1.0指标说明当前受控样本没有
观察到漏误检，不外推为多人、跨人员、低照度或公开数据集精度。
